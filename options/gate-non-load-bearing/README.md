# Decision — Gate Non-Load-Bearing Set

**The decision.** The concrete set of requirements the gate holds *not* load-bearing for a
generation's requirement gate — the change-process and human-governance-act requirements that
conformance-gate.md §"Requirements That Do Not Gate A Generation" carves out — recorded here so that
two builds judge against an identical load-bearing set.

**Requirements any choice must satisfy (from the spec — do not weaken):**
- A change-process or human-governance-act requirement is not load-bearing for a generation, but
  still binds to an enforcing line of another kind (conformance-gate.md §"Every Requirement Binds To
  An Enforcing Line", §"A Change-Process Requirement Is Not Load-Bearing For A Generation").
- The excluded set is recorded at this declared-default location so the load-bearing set is
  reproducible.

## Choices

- [`change-process-and-excluded`](./change-process-and-excluded.md) — the constitution's Governance
  Floors and Amendment Discipline, the contracts' Additive Evolution sections, and the enforceability
  meta-requirements, each routed to a change-process enforcing line. **The default.**

DEFAULT: change-process-and-excluded
